# Description

So there's lightweight universal `gayken` for nvk bundle. \
This is a long-awaited update with support of all products. \
Activation now is pretty simple, you dont need anymore additional actions to activate bundle - now Eeverything is done `automatically`.

# Installation

### From github (just a few steps - about 6)

1. Install [ReaPack](https://reapack.com)
2. Copy and paste the following URL in `Extensions -> ReaPack -> Import repositories...`

**nvkBundle repository (only if not installed yet)**
```
https://nvk.tools/index.xml
```

3. Copy and paste the following URL in `Extensions -> ReaPack -> Import repositories...`

**nvkToolsBundleLicense repository**
```
https://github.com/L0wl/nvkToolsBundleLicense/raw/index/index.xml
```

4. Go to `Actions -> Show action list...` and enter search query below

**Action search query**
```
nvkToolsBundleLicense - Installer.lua
```

5. Run this action

> [!NOTE]
> **You must run this action only once.** \
> On next launch of reaper, license will be automatically regenerated to fit your timezone or, whatever

6. Enjoy
