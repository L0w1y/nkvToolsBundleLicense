# Описание

Универсальный `гейкен` для nvk bundle. \
Это долгожданное обновление с поддержкой всех продуктов. \
Активация теперь предельно проста - больше никаких дополнительных действий для активации бандла. Всё происходит `автоматически`.

# Установка

### С GitHub (всего несколько шагов - около 6)

1. Установите [ReaPack](https://reapack.com)
2. Скопируйте и вставьте следующий URL в `Extensions -> ReaPack -> Import repositories...`

**Репозиторий nvkBundle (только если ещё не установлен)**
```
https://nvk.tools/index.xml
```

3. Скопируйте и вставьте следующий URL в `Extensions -> ReaPack -> Import repositories...`

**Репозиторий nvkToolsBundleLicense**
```
https://github.com/L0wl/nvkToolsBundleLicense/raw/index/index.xml
```

4. Перейдите в `Actions -> Show action list...` и введите поисковый запрос ниже

**Поисковый запрос**
```
nvkToolsBundleLicense - Installer.lua
```

5. Запустите action

> [!NOTE]
> **Это действие нужно выполнить только один раз.** \
> При следующем запуске Reaper, лицензия будет автоматически перегенерирована под ваш часовой пояс

6. Готово!
